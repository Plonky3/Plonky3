# Plonky3 vectors for the additive transform over the Wiedemann tower.
#
# Let v_0, v_1, ... be the Cantor basis, v_0 = 1 and v_i^2 + v_i = v_{i-1}.
# Write D(i) for the sum of the v_r whose index bit r is set in i.
#
# Let V_j be the polynomial vanishing on { D(m) : m < 2^j }, as the product of x + D(m).
# Let N_j be V_j divided by V_j evaluated at v_j, so that N_j(v_j) = 1.
# The novel basis is X_j = the product of the N_r whose index bit r is set in j.
#
# A transform of length 2^L over a coset takes coefficients c_0 .. c_{2^L - 1} in that basis
# to values y_i = sum over j of c_j times X_j evaluated at shift + D(i).
# Both the coefficient index and the value index are in natural order.
#
# Records are:
#
#   transform <bits> <L> <shift>   opens a case at that level, length and coset
#   coeff <i> <hex>                one input coefficient
#   value <i> <hex>                one output value
#
# Every element is a big-endian hex integer in the tower layout, padded to the level's width.
#
# The values were computed from the definitions above, not dumped from this crate's transform.
